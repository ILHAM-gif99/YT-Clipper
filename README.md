# 🎬 YT Clipper

YT Clipper is a simple web application that allows users to download YouTube videos and cut them into clips based on a selected start and end time.

The project is designed as a local video processing tool with a simple and user-friendly interface.

## ✨ Features

* 🔗 Download videos using a YouTube URL
* ✂️ Cut videos by selecting start and end time
* 🎥 Support high-quality video output
* ⚡ Local video processing
* 📥 Download the generated clip
* 🖥️ Simple and responsive interface

## 🛠️ Technologies

* Laravel
* PHP
* FFmpeg
* yt-dlp
* JavaScript
* HTML & CSS

## 🚀 How It Works

1. Paste a YouTube video URL.
2. Download the video.
3. Select the start and end time.
4. Process the video using FFmpeg.
5. Download the resulting clip.

## 📌 Project Purpose

This project was created as a learning and portfolio project to explore video processing, FFmpeg integration, and web application development using Laravel.
